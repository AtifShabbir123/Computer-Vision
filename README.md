# Computer Vision

## About This Repository

This repository is created for learning the basics of computer vision using Python and OpenCV.

## Files

The `Files` folder contains the `images.py` Python script. The script uses the OpenCV library to load an image from the `Images` folder and display it on the screen.

## Images

The `Images` folder contains two sample images. The images are used to test the Python OpenCV script and demonstrate how images can be loaded and displayed using OpenCV.

## Requirements

To run the Python script, Python and the OpenCV library are required.

Install OpenCV using:

```bash
pip install opencv-python
```

## How to Run

Run the `images.py` file using Python:

```bash
python images.py
```
